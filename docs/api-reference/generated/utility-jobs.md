## GetJobStatus

`rack_manager.RackManager/GetJobStatus`

GetJobStatus returns the current state of a job including its results if finished. If the job has any associated child jobs, it is possible to query results for all jobs with a single call.

| Property | Value |
| --- | --- |
| Execution | **Synchronous.** The response carries the full result. |
| Target | **Not node-specific.** Acts on the service, the firmware catalog, or a job. |
| Behavior details | [Operations guide](../../operations/utility.md) |
| Protobuf reference | [`GetJobStatus`](/rms/api-reference/protobuf-reference/rack-manager/rack-manager/rack-manager-get-job-status) |

**Request:** [`GetJobStatusRequest`](types-rack-manager.md#getjobstatusrequest)

| Field | Type | Description |
| --- | --- | --- |
| `job_id` | `string` | ID of the job to query |
| `include_child_job_states` | `bool` | Whether to include results of child jobs. This is disabled by default |

**Response:** [`GetJobStatusResponse`](types-rack-manager.md#getjobstatusresponse)

| Field | Type | Description |
| --- | --- | --- |
| `job_states` | repeated [`JobStatus`](types-rack-manager.md#jobstatus) | States of all jobs queried If a parent job is queried, it will be the first in the result list |

**Errors:** Refer to [Conventions](../conventions.md#error-handling) for how RMS reports failures. This RPC also returns these gRPC errors:

- `INVALID_ARGUMENT`: The `job_id` is empty.
- `NOT_FOUND`: No tracked job has the supplied `job_id`.

<Accordion title="Example request">

