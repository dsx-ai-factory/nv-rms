## StartSystemValidation (V2)

`rack_manager_v2.RackManagerV2/StartSystemValidation`

StartSystemValidation launches an NVSSVT system validation scan against each Device Under Test (DUT) in the request, each as its own asynchronous RMS job. NVSSVT itself may run for a long time, and each node's scan runs independently: one node's admission or launch failure does not affect any other node's scan.

Returns a parent job_id (response.job_id); poll it via rack_manager.GetJobStatus to track the batch as a whole. Each admitted node's own scan job_id is also returned in `jobs`, for polling and result retrieval scoped to that node. On completion, each scan job's rack_manager.JobStatus.result_json holds its parsed per-DUT status and summary report JSON.

<Warning>
Each node's scan runs as its own job. A failure to admit or launch one node does not affect the other nodes.
</Warning>

| Job result | `result_json` in the job status holds the parsed status and the summary report for that node's scan. |
| Target | **Caller-supplied nodes.** The request carries each node's endpoints and credentials, and RMS does not store them. |
