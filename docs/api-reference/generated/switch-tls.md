# Switch TLS and Certificates

Install switch mTLS certificates and disable switch mTLS.

| RPC | Execution | Summary |
| --- | --- | --- |
| [`ConfigureSwitchCertificate`](#configureswitchcertificate) | Asynchronous, parent and child jobs | ConfigureSwitchCertificate initiates asynchronous RMS-configured TLS certificate installation on all supplied switches. |
| [`BatchDisableSwitchMtls`](#batchdisableswitchmtls) | Asynchronous, parent and child jobs | BatchDisableSwitchMtls asynchronously disables mTLS for selected services on caller-supplied switches. |

For definitions of execution modes and job polling, refer to [Async jobs](../async-jobs.md).

## ConfigureSwitchCertificate

`rack_manager.RackManager/ConfigureSwitchCertificate`

ConfigureSwitchCertificate initiates asynchronous RMS-configured TLS certificate installation on all supplied switches. Returns a parent job ID for tracking overall progress, along with individual child job IDs per switch.

| Property | Value |
| --- | --- |
| Execution | **Asynchronous, parent and child jobs.** The response returns a parent job ID and the work continues after the call returns. |
| Job tracking | Poll [`GetConfigureSwitchCertificateJobStatus`](utility-jobs.md#getconfigureswitchcertificatejobstatus) with the job ID in `response.job_id`. Per-node child job IDs are in `jobs`. |
| Target | **Caller-supplied nodes.** The request carries each node's endpoints and credentials, and RMS does not store them. |
| Behavior details | [Operations guide](../../operations/switch-management.md) |
| Protobuf reference | [`ConfigureSwitchCertificate`](/rms/api-reference/protobuf-reference/rack-manager/rack-manager/rack-manager-configure-switch-certificate) |

**Request:** [`ConfigureSwitchCertificateRequest`](types-rack-manager.md#configureswitchcertificaterequest)

| Field | Type | Description |
| --- | --- | --- |
| `nodes` | [`NodeSet`](types-rack-manager.md#nodeset) | Switch nodes to update |
| `services` | repeated [`SwitchService`](types-rack-manager.md#switchservice) | Switch services to protect with the installed mTLS certificates |
| `test_hello` | `bool` | Test Hello Connection over mTLS |
| `domain` | optional `string` | Optional site selector; defaults to --default-switch-domain when unset. |

**Response:** [`ConfigureSwitchCertificateResponse`](types-rack-manager.md#configureswitchcertificateresponse)

| Field | Type | Description |
| --- | --- | --- |
| `response` | [`NodeBatchResponse`](types-rack-manager.md#nodebatchresponse) | response.job_id is parent job id |
| `jobs` | repeated [`ConfigureSwitchCertificateJobInfo`](types-rack-manager.md#configureswitchcertificatejobinfo) | Individual child job ID per switch |

**Errors:** Refer to [Conventions](../conventions.md#error-handling) for how RMS reports failures.

## BatchDisableSwitchMtls

`rack_manager.RackManager/BatchDisableSwitchMtls`

BatchDisableSwitchMtls asynchronously disables mTLS for selected services on caller-supplied switches. Returns a parent job ID for GetJobStatus.

| Property | Value |
| --- | --- |
| Execution | **Asynchronous, parent and child jobs.** The response returns a parent job ID and the work continues after the call returns. |
| Job tracking | Poll [`GetJobStatus`](utility-jobs.md#getjobstatus) with the job ID in `response.job_id`. Set `include_child_job_states` on `GetJobStatus` to read per-node child jobs. |
| Target | **Caller-supplied nodes.** The request carries each node's endpoints and credentials, and RMS does not store them. |
| Behavior details | [Operations guide](../../operations/switch-management.md) |
| Protobuf reference | [`BatchDisableSwitchMtls`](/rms/api-reference/protobuf-reference/rack-manager/rack-manager/rack-manager-batch-disable-switch-mtls) |

**Request:** [`BatchDisableSwitchMtlsRequest`](types-rack-manager.md#batchdisableswitchmtlsrequest)

| Field | Type | Description |
| --- | --- | --- |
| `nodes` | [`NodeSet`](types-rack-manager.md#nodeset) | Target switch identities and direct connection information |
| `services` | repeated [`SwitchService`](types-rack-manager.md#switchservice) | Switch services that should stop requiring mTLS |

**Response:** [`BatchDisableSwitchMtlsResponse`](types-rack-manager.md#batchdisableswitchmtlsresponse)

| Field | Type | Description |
| --- | --- | --- |
| `response` | [`NodeBatchResponse`](types-rack-manager.md#nodebatchresponse) | response.job_id is the parent job ID for GetJobStatus |

**Errors:** Refer to [Conventions](../conventions.md#error-handling) for how RMS reports failures.
