## AddFirmwareObject

`rack_manager.RackManager/AddFirmwareObject`

AddFirmwareObject adds a firmware object catalog entry.

RMS may download the referenced artifacts asynchronously after accepting the object. Use GetFirmwareObject or ListFirmwareObjects and check FirmwareObject.available before applying it.

<Warning>
The call returns after RMS stores the object. RMS downloads the referenced artifacts in the background. Call `GetFirmwareObject` or `ListFirmwareObjects` and wait for `FirmwareObject.available` before you apply the object.
</Warning>
